## ShopBack 淘寶回贈點樣計？真實例子拆解

好多人以為「10% 回贈」即係買 ¥100 就返 ¥10，其實要睇幾個因素。

**第一，回贈係按成交價計，唔係按標價計。** 即係如果你用咗優惠券壓低咗成交價，回贈會以折後價為基準。例如一件衫原價 ¥200，你用券減到 ¥150，回贈就係 ¥150 × 10% = ¥15。

**第二，回贈率因商戶而異。** 淘寶上面咁多賣家，每間同 ShopBack 嘅合作條件唔同，所以同一個品類，唔同店鋪嘅回贈率可能差好遠。ShopBack 喺商戶頁面會顯示當前嘅回贈率，落手前最好先睇清楚。

**第三，部分品類唔計回贈。** 例如用優惠券或優惠碼進行嘅消費、某啲特殊促銷商品，可能會唔符合回贈資格。ShopBack 官方條款寫明「優惠券或優惠碼進行的消費將不符合」，所以如果你想拎回贈，最好直接透過 ShopBack 跳轉結帳，唔好再喺結帳頁另外貼優惠碼。

**簡單計一計：** 假設你每個月淘寶使 ¥2,000（大約 HK$2,200），10% 回贈就係 ¥200，即係大約 HK$220 一個月。一年落嚟就係 HK$2,640，呢筆錢足夠你下次去日本食幾餐好嘢。如果你係 Plus 會員 12%，就再多少少。
